## Local investigation, separate from real host evidence

An isolated build of the existing CPU bridge was replayed on opaque white inputs
using the recorded defaults. Turning Grain off reduces its pixel-scale variation;
turning both Grain and Turbulence off leaves broad smooth structure. Thus simply
changing the palette is not a supported remedy. The replay is not bit-exact with
the actual AE PNG; it does not reproduce the complete host color pipeline, so it
cannot certify a CPU/GPU repair or supply reference behavior for Cosmic.

Code inspection identifies pixel-coordinate noise scale and unweighted additive
grain in the current renderer. It also identifies a separate ROI concern: Depth
Rounding currently uses padded work-canvas dimensions. These are investigation
items, not completed native fixes. Do not tune one blended frame and call all
presets equivalent, or silently loosen the quality contract.
